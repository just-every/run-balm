## The intake link

Every booking gets a private, one-use link to the current intake form. The client opens it, answers the questions and selects **Send my intake form**. The form can be sent once; the link then shows when it was received.

The answers appear in the client's file under **Intake forms**, for their practitioner and the owner. Reception sees only that the form was received. Each set of answers keeps the exact version of the form it answered.

## The questions

The first version, **New client intake**, asks:

- What brings you in? (required)
- How long has this been going on, and has it happened before?
- Medical conditions, injuries or surgeries we should know about
- Current medications
- Emergency contact name and phone (required)
- A consent to assessment and treatment (required)

## Publish a new version

On **Intake form** (owner only), the **Prepare a new version** panel starts from the current questions:

1. Edit the **Form title** if you like.
2. For each question, change its wording under **Question**, pick its **Answer type** (**Short answer**, **Long answer**, **Tick box (yes or no)** or **Date**) and tick **Patients must answer** for a required question.
3. Use **Move up** and **Move down** to reorder questions, **Remove** to drop one, and **Add a question** for a new empty one at the end.
4. Select **Prepare draft**. Your edits are kept on the page until you do; nothing changes for clients yet.
5. Under **Prepared versions**, check the draft and select **Publish as the new version**.

New bookings get the new version. Published versions never change, and each set of answers keeps the version it answered; earlier versions stay listed with their dates. An agent with a key can also prepare a version for you to publish ([Agent commands](/docs/agent-commands)).
