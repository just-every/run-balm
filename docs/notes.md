## Write a note

A practitioner opens **Clients**, then the client's file. Under **Treatment notes**, **Write a treatment note** lists the practitioner's own appointments with that client. Choose the visit, write the note and select **Save note**.

A note is plain text, for example:

```text
S: L knee pain 6/10 running, stairs.
O: Reduced knee flexion, tender medial joint line.
A: Likely patellofemoral pain.
P: Quads and hip program, review 2 weeks.
```

## Who reads it

Only the practitioner who wrote a note and the clinic owner can read it. Reception and other practitioners see that notes are private instead. Every read is recorded in the file's access audit.

## Amend a note

Open **Amend this note**, write the corrected text and the **Reason for amendment**, and select **Save amendment**. Balm adds a numbered revision; the earlier text is never rewritten and stays under **Earlier revisions**.
