# INS-013 implementation sources

- CMS Claims Processing Manual, chapter 28, crossover carrier mapping: https://www.cms.gov/Regulations-and-Guidance/Guidance/Manuals/Downloads/clm104c28.pdf and transmittal https://www.cms.gov/regulations-and-guidance/guidance/transmittals/downloads/r2810cp.pdf . Forwarded claim status 19/20/21 requires named 2100 NM1*TT carrier; that carrier must match the next stored policy.
- CMS professional 4010/5010 crosswalk: https://www.cms.hhs.gov/ElectronicBillingEDITrans/Downloads/ProfessionalClaim4010A1to5010.pdf . 2430 DTP*573 is the adjudication or payment date. The serializer uses the actual BPR payment date from the ERA or explicit original EOB line date, never today's date.
- pyx12 official project documentation: https://pyx12.readthedocs.io/en/latest/quickstart.html . The independent validator checks HIPAA 5010 X222A1 using its own maps. `tests/cob-validator.mjs` emits the production serializer's secondary and tertiary outputs; those files must pass `x12valid` before claiming conformance. Its synthetic inputs are serializer inputs, not application data.
- CMS paper form: https://www.cms.gov/medicare/coding-billing/electronic-billing/professional-paper-claim-form ; NUCC instructions https://www.nucc.org/images/stories/PDF/1500_claim_form_instruction_manual_2025_07-v13.pdf . Print the claim overlay at 100% on approved 02/12 red stock, review alignment and sign box 31; download and attach the fixed primary EOB. Preparing or printing records no submission. The biller records actual mailing/payer receipt separately.

No clearinghouse submission, payer certification, live claims or live carrier ERA was attempted. Independent file validation is not payer acceptance. Collection holds have no automatic timeout: only an explicit owner decision after a configured wait with recorded contract/policy provenance can release an unfinished payer chain. The configured wait and explicit human billing decision implement INS-013’s existing clause text; no automatic release or outbound action is introduced. Print alignment is measured against the NUCC 02/12 template/grid (https://www.nucc.org/images/stories/PDF/1500_claim_form_2012_02.pdf); the practice still calibrates its physical printer against its approved stock. Authorizations, assignment and provider signatures remain explicit review fields, never inferred.

Public-door outputs `.cache/cob-public/secondary.x12` and `.cache/cob-public/tertiary.x12` passed pyx12 2.3.3’s unmodified X222A1 maps in heavy-slot run `20261023T010850282130Z-heavy-slot-c4549c5d`. The Python API uses a text acknowledgment stream because that release’s CLI opens its acknowledgment in binary mode; this changes no validation rule. `tests/cob-browser.mjs` exercises the real packet preparation, original attachment download and separate actual-submission forms, held/released ledger and capped copay at 1440/390; the final print check also saves Chromium’s actual Letter-size output for comparison to the NUCC grid.
